## The word

**irregardless**

It is not a word. It is a double negative wearing a dictionary entry as a
disguise: "ir-" + "regardless" says "not regardless", which means the
opposite of what anyone using it means. "Regardless" already exists and
already does the whole job, correctly, in fewer letters — so deleting
"irregardless" removes nothing from the language except the argument about
whether it counts as a word. The dictionary entry has spent a century
carrying a footnote that says "nonstandard": a word the dictionary
apologises for while it prints it.

## How it works

`main.ts` writes exactly one word, spelled correctly, with nothing else
attached, to `/output/entry.txt`:

```
irregardless
```

Run it with Node 22.18 or later:

```
node main.ts
```
